在 **V1 状态管理** 体系里，只有 `@State` / `@Link` / `@Provide` / `@Prop` 等“组件内”装饰器，**不支持**跨组件直接订阅一个外部对象。  
因此要想“普通单例 → `@Component`”实时刷新，只能走 **事件总线** 或 **回调注册** 方式：  
**单例里把变化发出去 → 组件自己把值写进自己的 `@State`**。

下面给出 **零依赖、可插拔** 的“最小实现”，完全兼容现有 `@Component` 代码。

------------------------------------------------
一、定义“事件总线”（纯 TS，无装饰器）

```ts
// CookieEvent.ets
export type CookieListener = (cookie: string, isLoggedIn: boolean) => void;

class CookieEventBus {
  private listeners: CookieListener[] = [];

  // 注册
  onCookieChange(fn: CookieListener) {
    this.listeners.push(fn);
  }

  // 注销
  offCookieChange(fn: CookieListener) {
    const idx = this.listeners.indexOf(fn);
    if (idx >= 0) this.listeners.splice(idx, 1);
  }

  // 触发
  emit(cookie: string, isLoggedIn: boolean) {
    this.listeners.forEach(fn => fn(cookie, isLoggedIn));
  }
}

export const cookieBus = new CookieEventBus();
```

------------------------------------------------
二、在 `CookieManager` 里**发事件**

```ts
// CookieManager.ets（片段）
import { cookieBus } from './CookieEvent';

export class CookieManager {
  ...
  private notify(host: string): void {
    const header = this.cookieStore.get(host) ?? '';
    const isLoggedIn = header.includes('JSESSIONID'); // 你的业务规则
    cookieBus.emit(header, isLoggedIn);
    hilog.info(DOMAIN, TAG, '🔔 [Notify] 已广播，isLoggedIn=%{public}s', isLoggedIn);
  }

  public async saveCookie(host: string, setCookieValues: string | string[]): Promise<void> {
    ... /* 原有逻辑不变 */
    this.notify(host);   // ➜ 新增
  }

  public async clearAllCookies(): Promise<void> {
    this.cookieStore.clear();
    cookieBus.emit('', false);   // ➜ 新增
  }
}
```

------------------------------------------------
三、在组件里**订阅 + 写 `@State`**

```ts
// UserBadge.ets（仍是 @Component）
@Component
export struct UserBadge {
  @State isLoggedIn: boolean = false;
  @State cookieStr   : string = '';

  // 把回调保存到实例属性，方便 aboutToDisappear 注销
  private listener: CookieListener = (cookie, logged) => {
    this.cookieStr   = cookie;
    this.isLoggedIn  = logged;
  };

  aboutToAppear() {
    // 立即读一次
    CookieManager.getInstance().getCookie().then(c => {
      this.cookieStr  = c;
      this.isLoggedIn = c.includes('JSESSIONID');
    });
    // 再注册后续刷新
    cookieBus.onCookieChange(this.listener);
  }

  aboutToDisappear() {
    cookieBus.offCookieChange(this.listener);
  }

  build() {
    Row() {
      if (this.isLoggedIn) {
        Text('已登录').fontColor(Color.Green)
      } else {
        Text('未登录').fontColor(Color.Gray)
      }
    }
  }
}
```

------------------------------------------------
四、使用小结

| 问题                      | V1 方案                                              |
| ------------------------- | ---------------------------------------------------- |
| 普通单例 → 组件实时刷新？ | **事件总线** 把变化推出去                            |
| 组件如何接收？            | 在 `aboutToAppear` 注册回调，把值写进自己的 `@State` |
| 需要改装饰器吗？          | 不需要，保持 `@Component` 即可                       |
| 支持跨页面吗？            | 支持，只要 `cookieBus` 是同一个单例                  |

这样即可在**不升级任何组件到 V2**的前提下，实现“CookieManager 状态 → 所有 `@Component` 实时刷新”。
